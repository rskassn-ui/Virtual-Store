# Virtual-Store

Local agents for this computer live in this repository.

## RSKA Assistant

`rska-assistant` is a local Grok agent for the Ryukyu Shorinji-Ryu Karate Association. It talks in the playground, searches the web, uses files on this computer, and writes code. Association facts are stored in the project. Run it from that directory with `npx @grok/agent-sdk dev`, then open [http://127.0.0.1:3000/playground](http://127.0.0.1:3000/playground).
